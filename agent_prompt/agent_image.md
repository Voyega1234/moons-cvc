สร้างภาพโฆษณาที่สมบูรณ์จาก Campaign Input และรูปภาพที่แนบมา

เริ่มจากทำความเข้าใจไอเดีย วัตถุประสงค์ และสินค้าที่ไอเดียพูดถึง แล้วตัดสินใจเองว่าองค์ประกอบใดควรปรากฏในภาพ หากไอเดียระบุสินค้าตัวใด ต้องใช้สินค้าตัวนั้น และไม่เพิ่มสินค้าที่ไม่เกี่ยวข้อง แต่ไม่อยากได้ภาพที่ข้อมูลอัดแน่นเยอะ element เยอะเกินไป อยากให้ภาพมีพื้นที่ space balance สายตา เล่นกับการจัดวาง การใช้มุมกล้อง เทคนิคต่างๆ การใช้กราฟิกในการทำให้ภาพน่าสนใจ แทนการวางข้อมูลเต็มภาพ , text และสไตล์ของ font ที่ใช้ต้องเป็นส่วนหนึ่งของภาพ มีแล้วทำให้ภาพดูสมบูรณ์ขึ้นไม่ใช่ด้อยหรือเป็นจุดอ่อน เลือกใช้ให้เหมาะสม

การใช้ภาพ reference:
- วิเคราะห์ว่าอะไรคือ visual essence ที่ทำให้ reference โดดเด่นและจดจำได้ เช่น แนวคิดหลัก วิธีนำเสนอหรือ interaction กับสินค้า composition และ visual rhythm มุมกล้องและ framing แสง สี บรรยากาศ typography หรือ graphic treatment
- เลือกนำเฉพาะคุณลักษณะที่เหมาะกับไอเดียและแบรนด์มาพัฒนาเป็นงานใหม่ ไม่จำเป็นต้องใช้ทุกอย่างจาก reference และไม่ต้องคัดลอกภาพต้นฉบับตรง ๆ
- ให้น้ำหนักกับ visual idea ที่โดดเด่นและมีความหมาย มากกว่าการหยิบมาเพียงสีหรือ mood แบบผิวเผิน
- หากจุดเด่นของ reference คือวิธีที่คน มือ วัตถุ หรือสินค้า interact กัน และเหมาะกับไอเดีย ให้ประยุกต์ interaction นั้นกับสินค้าของเรา
- หากจุดเด่นคือระบบการจัดวาง มุมกล้อง แสง บรรยากาศ typography หรือ graphic treatment ให้ประยุกต์สิ่งนั้นตามความเหมาะสม
- หากบางส่วนของ reference ขัดกับไอเดีย สินค้า หรือข้อมูลจริง ไม่จำเป็นต้องนำมาใช้

ผลงานต้องเป็น original execution สำหรับ campaign นี้ แต่ยังเห็นความสัมพันธ์ทางภาพกับ reference อย่างชัดเจน อย่าลดการใช้ reference เหลือเพียงพื้นหลังหรือโทนสี และอย่าบังคับใช้ composition เดิมหากมันไม่เหมาะกับไอเดีย

การใช้รูปสินค้าและ materials:
- ใช้รูปสินค้าเพื่อรักษาตัวตนที่มองเห็นได้ของสินค้า ได้แก่ รูปร่าง บรรจุภัณฑ์ ฉลาก สี สัดส่วน วัสดุ และรายละเอียดสำคัญ
- ห้ามนำพื้นหลัง พื้นผิว แท่นวาง props ฉาก มุมกล้อง crop แสง หรือการจัดวางจากรูปสินค้าไปใช้ เว้นแต่รูปนั้นถูกระบุให้ทำหน้าที่เป็น reference ด้วย
- ทำให้สินค้ากลมกลืนกับฉากใหม่อย่างเป็นธรรมชาติ มี scale, perspective, lighting, contact และ shadow ที่น่าเชื่อถือ

เมื่อมี reference หลายภาพ ให้ใช้หน้าที่ที่ระบุของแต่ละภาพและรวมเฉพาะคุณลักษณะที่เข้ากันได้ อย่าเฉลี่ยทุกภาพเข้าด้วยกันจนทิศทางหลักไม่ชัดเจน

จัดวางข้อความและรายละเอียดโปรโมชันเท่าที่จำเป็น ให้มีจุดสื่อสารหลักชัดเจน อ่านง่าย สบายตา และดูเป็นภาพโฆษณาที่เสร็จสมบูรณ์พร้อมใช้งานจริง อย่าใส่ข้อความหรือสรรพคุณมากเกินไป และอย่าสร้าง layout โฆษณาสำเร็จรูปซ้ำ ๆ หาก reference และไอเดียเสนอวิธีนำเสนอที่น่าสนใจกว่า
