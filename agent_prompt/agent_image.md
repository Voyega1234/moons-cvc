สร้างภาพโฆษณาจากข้อมูลและรูปที่แนบมา โดยให้วิเคราะห์เองว่า:

input ทั้ง text และ รูปภาพไหนควรจะใส่ลงในรูป โดยมีข้อบังคับคือ ถ้าในไอเดียพูดถึงสินค้าตัวไหนต้องใช้อันนั้น และ ดูว่ารูปไหนเป็น reference  

เอาภาพ reference ที่แนบเอามาเป็นของตัวเอง โดยปรับให้เข้ากับแบรนด์และไอเดีย โดยพยายามเรียนรู้ทุกอย่างในภาพ ref เลย แต่ไม่ได้ลอกภาพมาเลยนะแต่ปรับให้เข้ากับไอเดียและแบรนด์ของเรา
และอารมณ์ของภาพอ้างอิงมาประยุกต์ใช้กับสินค้าที่แนบมา โดยไม่คัดลอกภาพเดิมตรง ๆ

จัดวางข้อความและรายละเอียดโปรโมชันจากข้อมูลที่ให้มาให้เหมาะกับภาพ อ่านง่าย และดูเป็นงานโฆษณาที่เสร็จสมบูรณ์ พร้อมใช้งานจริง ไม่อยากได้ภาพที่ตัวหนังสือรกเยอะ มีสรรพคุณเยอะจนทำให้ภาพดูแน่น มีได้ แต่ต้องจัดวางให้มันพอดี สบายตา เคารพหลัก Design Principle 

ใช้เทคนิค
Contrast: สร้างความต่างของสีและขนาด เพื่อให้จุดเด่นเด้งสะดุดตาออกมาจากพื้นหลัง
Hierarchy: เรียงลำดับความสำคัญของข้อความ โดยให้หัวข้อหลักใหญ่ที่สุด เพื่อให้คนอ่านตามลำดับ
Clarity: สื่อสารข้อความเดียวที่ชัดเจน ไม่ใส่รายละเอียดเยอะเกินไปจนคนดูสับสน
Whitespace: เว้นพื้นที่ว่างรอบตัวสินค้าและข้อความ เพื่อช่วยพักสายตาและทำให้ภาพดูแพง
Alignment: จัดวางองค์ประกอบให้เป็นระเบียบตามแนวเส้นตรง เพื่อให้อ่านง่ายและดูเป็นมืออาชีพ
Balance: กระจายน้ำหนักของภาพซ้ายขวาให้สมดุล ไม่เทน้ำหนักไปฝั่งใดฝั่งหนึ่งจนอึดอัด
Repetition: ใช้สี ฟอนต์ หรือกราฟิกซ้ำๆ เพื่อสร้างการจดจำและคุมโทนภาพลักษณ์ของแบรนด์
Rule of Thirds: จุดตัด 9 ช่อง วางสิ่งสำคัญ (เช่น ตัวสินค้า) ไว้บริเวณจุดตัดเพื่อดึงสายตาได้ดีที่สุด
