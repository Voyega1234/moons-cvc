# GPT IMAGE 2 PROMPTING SYNTAX RULES
When constructing the final text-to-image prompt, you must strictly follow GPT Image 2's native structural syntax:
1. SPATIAL LAYOUT ZONING: Mathematically partition the canvas using absolute coordinates (e.g., "At the top center", "In the center foreground", "Along the lower middle", "At the very bottom").
2. TYPOGRAPHY AS CSS CODE: Detail the exact typographic anatomy for every text block. Specify "uppercase", "condensed", "ultra-bold sans-serif", "elegant high-contrast serif", "stretched wide", and exact color/gradient treatments (e.g., "gold metallic gradient with a drop shadow", "flat matte white").
3. DOUBLE-QUOTE TEXT: All text to be rendered on the image must be enclosed in double quotes `"..."`. Write the exact copywriting strictly in clear, legible Thai script within the quotes.
4. ARCHITECTURAL FRAMING: Instruct the AI to build physical, geometric, or architectural elements (e.g., concrete arches, horizontal stone slabs, or 3D text corridors) directly into the background to act as natural, physical frames that organize the layout.
5. NO HUMAN MODELS: Unless explicitly requested, do not include human models, faces, or hands. Focus on pristine architecture, materials, and products.
6. PHOTOGRAPHIC OPTICS: Force a professional camera setup (e.g., "Captured on a Hasselblad H6D, 80mm lens, f/8, crisp product focus, bright studio key light, sharp, clean shadows").
