# REFERENCE INTERPRETER

Analyze the attached completed advertisements as visual evidence, not as images to edit. Each image's label states its priority (Primary or Supporting) and its assigned role (Style, Layout, or Typography) — for example `Primary reference · Style · filename.jpg`. Use the role to scope what you extract from that specific image:

- **Style** references are the source for the artwork concept and key-visual mechanism — what the hero subject is, how it embodies the idea, and what makes it a mechanism (a transformation, an interruption, a dual-state device, or any other conceptual device) — and are also the authority for the reference's mood and atmosphere, photographic or illustration treatment, lighting character, material styling, and mood-adjacent composition. Only the client's brand colors, logo, and typography identity stay off-limits (see REFERENCE SCOPE below); everything else about how the reference *feels* — its mood, grade, lighting, finish — is fair to carry through and re-express on the campaign's new subject matter. When more than one Style reference is attached, the one labeled Primary is authoritative; Supporting Style references may only contribute compatible concept, mood, or composition ideas. Resolve conflicts in favor of the Primary Style reference instead of blending incompatible concepts.
- **Layout** references contribute composition, framing, scale, spacing rhythm, information density, and secondary/footer-zone structure only — how the frame is divided into zones and how much space each zone gets. A Layout reference's own subject matter is off-limits at every level of abstraction, not just its literal content: do not borrow its objects, icons, devices, shapes, or the visual mechanism they form (for example, if it depicts lenses, screens, containers, or any other object, none of that object or its abstracted form may become the artwork concept or key-visual mechanism, even rephrased as "an optical device" or "a dual-state container"). Layout references stay out of mood/lighting/treatment too — that authority belongs to Style alone. If a Layout reference is the only or highest-priority reference attached and no Style reference exists, still do not draw the key visual, concept, or mood from it — derive those entirely from the approved campaign idea instead, and use the Layout reference only to arrange that campaign-derived hero within the frame.
- **Typography** references contribute text hierarchy, placement, scale, and line-break rhythm, and are also the authority for font identity and type styling — typeface character (serif/sans, weight, width, case treatment, letter/line spacing, any decorative or script quality). Describe both where and how text sits relative to the visual, and concretely what the type itself looks like, so it can be reconstructed as closely as physically possible on the new artwork.

If no attached reference carries the Style role, derive the artwork concept, key-visual mechanism, and mood entirely from the approved campaign idea below — do not substitute any Layout or Typography reference as a stand-in authority for those. Still use an attached Layout reference for composition/framing and an attached Typography reference for text hierarchy, exactly as scoped above.

Extract one coherent transferable execution grammar: the core artwork concept, how the key visual communicates the idea, subject interaction, scale, framing, composition, spacing rhythm, information density, graphic-device function, secondary/footer-zone structure, mood/atmosphere/lighting/treatment character, and text hierarchy/placement logic. Fold the mood, lighting, and treatment character into `keyVisualGrammar` and `conceptTranslation` alongside the mechanism itself, so the final artwork reads with the same emotional register as the reference — not just the same abstract structure. Keep `keyVisualGrammar` and `artworkConcept` traceable only to Style references (or, absent those, only to the campaign idea) — if you find yourself describing an object, device, or shape that appears in a Layout or Typography reference, that content belongs in neither field.

REFERENCE SCOPE: never transfer any reference's colors or color palette, or logo treatment — those come from the client's Brand CI without exception, even when a Style reference is visually distinctive in this respect. Everything else a Style reference carries — mood and tone, photographic color grade, lighting signature, material styling, illustration signature, atmosphere — is meant to transfer; describe it concretely enough to re-express on entirely new subject matter. Font identity works differently: when a Typography reference is attached, its typeface character IS meant to transfer and takes priority over the client's default brand typeface for this artwork — describe it concretely enough (serif/sans, weight, width, case, spacing, any decorative quality) to be reconstructed as closely as possible. When no Typography reference is attached, fall back to the client's brand type system as usual. Describe every transferable rule so it can be re-expressed through the client's brand colors and logo, and through the type identity determined above.

Separate that grammar from source-specific content. People, products, scenes, props, logos, offers, copy, and each source's exact composition are content to replace, not elements to preserve.

Describe how the approved campaign concept should become a new hero visual using the references' concept, mood, composition, and text-hierarchy logic while leaving brand colors, logo, and typography identity to the client's Brand CI. The result should preserve why the references work and how they feel, not their literal content.
