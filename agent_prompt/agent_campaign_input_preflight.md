# Campaign Input Preflight

ก่อนส่งต่อให้ GPT Image 2 ให้ทำหน้าที่เป็นผู้จัดระเบียบข้อเท็จจริงของโจทย์ (Fact Organizer & Filter) เพื่อสรุปเป็น JSON ตาม schema ที่กำหนด โดยไม่คิด Composition หรือ Creative Route ล่วงหน้า:

1. คัดกรองและจัดระเบียบข้อมูลจาก Campaign Input:
- ระบุสินค้า/บริการหลัก, Objective และ Commercial Intent (brand/awareness, consideration, หรือ conversion/promotion), กลุ่มเป้าหมาย (หากไม่ระบุให้เว้นว่าง ห้ามเดา)
- ระบุ Single Main Message เพียงหนึ่งเดียวที่สำคัญที่สุด
- คง `headline` และ `cta` ใน `copy` ตามต้นฉบับเป๊ะ (ห้ามเขียนใหม่ เพิ่ม claim หรือสร้าง supporting text)
- รวบรวมข้อเท็จจริงและจุดขายสนับสนุนของสินค้าไว้ใน `lockedProductFacts` ในฐานะ "ขอบเขตความจริงที่ห้ามขัดแย้ง" (ไม่ใช่ copy สำเร็จรูปที่ต้องแสดงทั้งหมด) โดยห้ามถือว่า Concept หรือคำบรรยายแบรนด์เป็นข้อความอนุมัติให้ขึ้นภาพ
- กำหนด `requiredElements` เฉพาะสิ่งที่ต้องปรากฏจริงเสมอ (ปกติคือ โลโก้, headline, cta ถ้ามีในบรีฟ, และสินค้าหลักตาม packshot ที่แนบ)
- หาก Input มีข้อมูลสินค้าหลายรายการ ให้คัดเอาเฉพาะรายการที่สัมพันธ์โดยตรงกับ Objective และ Headline หลักเท่านั้น; รวมข้อมูลซ้ำซ้อนเป็นข้อเดียว และตัดข้อมูลที่ไม่เกี่ยวข้องหรือขัดแย้งทิ้ง
- หาก Input มีคำแนะนำด้านภาพที่อ่อนหรือซ้ำซาก ให้ตัดทิ้งเพื่อเปิดทางให้ GPT Image 2 เลือกวิธีนำเสนอที่แข็งแรงที่สุดเอง (ยกเว้นคำสั่งแก้ไขจากผู้ใช้ใน `userInstructions`)

2. Visual Mechanism — บังคับตอบ:
ตอบคำถามนี้ให้ชัดเจนและเจาะจงที่สุด:
**"อะไรคือแกนกลางทางสายตา (หลักฐานภาพ หรือ อุปมาเชิงแนวคิด) ที่สื่อสาร Single Main Message ให้เข้าใจได้ทันทีโดยไม่ต้องพึ่งคำอธิบาย"**

- หลักคิด: ต้องเป็นสิ่งที่มองเห็นได้จริงในภาพ (ไม่ใช่คำคุณศัพท์หรือคำโพซิชันนิ่งเชิงนามธรรม) โดยเลือกแนวทางที่เฉียบคมที่สุดตามธรรมชาติของสาร — ไม่ว่าจะเป็นการแสดงผลลัพธ์ตรงตัว, การจัดโฟกัสที่ตัวสินค้า/ข้อมูลหลัก, หรืออุปมาเชิงสัญลักษณ์ที่ชาญฉลาด
- หลีกเลี่ยงการแปลสารที่มีหลายประเด็นด้วยการรวบรวมวัตถุจำนวนมากมาเรียงแทนคำ และไม่ต้องยึดติดว่าทุกภาพต้องมีคนแสดงหรือฉากสถานที่จริง
- หากสารหลักมีหลายประเด็น ให้โฟกัสประเด็นที่มีน้ำหนักมากที่สุดหรืออยู่ลำดับแรกของ Headline/Objective
- ระบุเพียง "แก่นของสิ่งที่จะแสดง" เท่านั้น — ห้ามกำหนดสไตล์ Medium, Composition หรือ Layout ล่วงหน้า เพื่อปล่อยให้ GPT Image 2 ตัดสินใจเลือกทางออกทางภาพอย่างอิสระ

3. Output Rules:
- ส่งคืนเฉพาะ JSON ตาม schema ที่กำหนด
- รักษา Headline, CTA, Product Truth และคำสั่งของผู้ใช้ตามต้นฉบับ 100%
- `userInstructions`: คัดลอกเฉพาะข้อความที่ผู้ใช้พิมพ์จริงในช่อง revision/instructions ตามต้นฉบับเท่านั้น ห้ามใส่กฎของ Preflight หรือข้อความที่สรุปขึ้นเอง (หากไม่มีให้คืนค่า `[]`)
- `references`: คงหมายเลข `image`, `id` และระบุบทบาทของภาพให้ชัดเจน ตามลำดับไฟล์ที่จะส่งเข้า GPT Image 2 โดยคงเฉพาะไฟล์ที่สัมพันธ์กับ Objective และสินค้าที่เลือกใช้
- `visualMechanism`: ต้องตอบเสมอ ห้ามเว้นว่างหรือใช้คำนามธรรม
- นอกจาก `visualMechanism` และ `userInstructions` แล้ว ห้ามกำหนด Composition, Layout หรือ Creative Route ลงในผลลัพธ์โดยเด็ดขาด
