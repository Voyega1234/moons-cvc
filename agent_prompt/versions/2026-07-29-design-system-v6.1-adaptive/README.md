# Design System V6.1 Adaptive

This is an experimental final-art prompt for the legacy `design-system` mode.
It broadens the V6 visual range without changing the archived V6 strategy and
creative-concept stages.

## Runtime chain

1. Strategy: inherited unchanged from
   `../2026-07-28-chol-static-03-v6/prompts/01-strategy-enrichment.exact.md`
2. Concept: inherited unchanged from
   `../2026-07-28-chol-static-03-v6/prompts/02-creative-concept-director.exact.md`
3. Final art:
   `prompts/03-design-system-v6.1-adaptive.md`

The V6.1 change is intentionally limited to final art direction. It treats
grid, hierarchy, controlled density, visual rest, and credible construction as
universal principles while allowing the visual language to adapt to the
brand, category, audience, objective, and format.

The archived V6 package remains available as the rollback baseline.

## Reference-corpus influence

The prompt was informed by a diverse multi-brand advertising corpus spanning
premium product work, retail promotions, children's products, technology,
travel, beauty, conceptual advertising, information design, and collage.
Reference files are not embedded in the runtime prompt and are not copied as
templates.
